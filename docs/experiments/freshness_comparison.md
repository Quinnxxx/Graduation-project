## 3. 实时库分析

### 3.1 当前状态

| 采集器 | 状态 | records | 说明 |
|---|---|---|---|
| `sample_jobs` | ✅ 链路闭环 | 10 条（固定） | 内置样例，publish_time 固定 |
| `jobsys` | ✅ 真实采集 | 广东高校就业网 jobsys 职位库抓取（首次模式约 10 页） | 服务端渲染、免登录无反爬，真实岗位入库；原 `tech_platform` 探查版测值已废弃 |

### 3.2 实时源口径变更（原 tech_platform 探查结论，已废弃）

> 以下探查结论取自已删除的 `tech_platform` 合规探查采集器，来源已废弃，仅作历史测值保留。

```json
{
  "source": "https://www.nowcoder.com/",
  "reachable": true,
  "robots_allowed": true,
  "detail": "首页 HTTP 200，robots.txt 未声明 Disallow: /",
  "note": "当前为合规探查版本，未抓取结构化岗位数据"
}
```

**探查结论**：
- 牛客网可达，robots 未禁止根路径
- 但无可稳定抓取的校招列表 JSON API / 静态页
- 按用户预设"不强行爬全站"，`parse()` 恒返回 `[]`

### 3.3 时效性预期（jobsys 新源口径，待重采验证）

## 4. 对比结论

### 4.1 时效性对比

| 维度 | 静态库 | 实时库（原 tech_platform 探查，已废弃） | 实时库（预期） |
|---|---|---|---|
| 平均天数 | 20 天 | N/A（探查版 0 条） | ≤ 7 天 |
| 数据更新 | 固定不变 | 无数据 | 每日增量 |
| 岗位有效性 | 可能已过期 | N/A | 在招状态 |

### 4.2 适用场景

| 场景 | 推荐 | 理由 |
|---|---|---|
| **演示/开发调试** | 静态库 | 数据稳定、字段完整、可复现 |
| **生产环境** | 实时库 | 时效性强、岗位真实、覆盖广 |
| **论文/答辩演示** | 静态库 + 实时库探查日志 | 展示链路闭环 + 合规探查能力 |

### 4.3 局限性

1. **静态库 publish_time 固定**：随时间推移数据"老化"，不适合长期生产使用
2. **实时库测值来源已废弃**：第 3、4 节实时库测值取自已删除的 `tech_platform` 合规探查版（`records=0`）；实时源已变更为 `jobsys`，时效性优势需按新源重采后确认
3. **演示数据公司名真实**：华为/网易/字节等 20 条演示数据使用真实公司名，但岗位为虚构

## 5. 后续建议

### 5.1 短期（当前阶段）

- **保留静态库**用于演示与开发调试
- **实时源已落地** `jobsys` 采集器（广东高校就业网 jobsys 职位库，真实岗位入库）
- 论文中说明实时库口径由 `tech_platform` 探查版变更为 `jobsys`

### 5.2 中期（接入真实源）

| 候选源 | 可行性 | 说明 |
|---|---|---|
| 牛客网校招 | ⚠️ 需进一步探查 | 当前 robots 允许但无稳定列表 API |
| 实习僧 | 待评估 | 公开页面，需验证 robots |
| 拉勾校招 | 待评估 | 可能需要登录 |
| 企业官方校招页 | 可行 | 逐个接入，如 hr.alibaba.com |

### 5.3 长期（生产化）

- 接入 3-5 个真实源，每日定时采集
- publish_time ≤ 7 天，过期岗位自动标记下架
- 字段完整度监控，低质量源告警

## 6. 原始数据

实验 SQL：

```sql
-- 静态库新鲜度
SELECT position_name, company_name, publish_time, 
       DATEDIFF(CURDATE(), publish_time) AS days_ago
FROM job_position 
WHERE source_url LIKE 'https://example.com/jobs/sample-%'
ORDER BY publish_time DESC;

-- 字段完整度
SELECT 
    SUM(CASE WHEN company_name IS NOT NULL AND company_name != '' THEN 1 ELSE 0 END) AS company_filled,
    ...
FROM job_position 
WHERE source_url LIKE 'https://example.com/jobs/sample-%';
```
