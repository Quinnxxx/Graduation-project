# Rerank 精排消融实验报告

> 实验日期：2026-09-28  
> 实验环境：Milvus v2.3.15 + 阿里云百炼 qwen3.7-text-rerank  
> 知识库规模：17 篇文档，4 种类型（技术面经/简历模板/面试技巧/行业知识）

---

## 1. 实验设计

### 1.1 检索架构

RAG 检索采用两阶段：
- **阶段1 向量召回**：query 向量化后在 Milvus 按 COSINE 相似度召回 `recall_k = min(top_k*3, 30)` 条
- **阶段2 Rerank 精排**：百炼 qwen3.7-text-rerank 按语义相关性重排取 top_k

`enable_rerank=False` 时仅向量召回，供对比实验。

### 1.2 评估指标

| 指标 | 公式 | 说明 |
|---|---|---|
| **Precision@k** | top-k 中命中 ground truth 的文档数 / k | 精确率 |
| **Recall@k** | top-k 中命中 ground truth 的文档数 / ground truth 总数 | 召回率 |
| **MRR** | 1 / 首个命中 ground truth 的排名 | 平均倒数排名 |
| **延迟** | 检索总时间（ms） | 包含向量召回 + 精排（若启用） |

## 3. 结论与分析

### 3.1 核心发现

| 指标 | rerank | norank | 差异 |
|---|---|---|---|
| Precision@1 | 1.000 | 1.000 | **持平** |
| Precision@3 | 0.467 | 0.500 | norank **+7%** |
| Precision@5 | 0.280 | 0.300 | norank **+7%** |
| Recall@1 | 0.733 | 0.733 | **持平** |
| Recall@3 | 0.917 | 0.950 | norank **+4%** |
| Recall@5 | 0.917 | 0.950 | norank **+4%** |
| MRR | 1.000 | 1.000 | **持平** |
| 延迟 | 2761ms | 2300ms | rerank **+20%** |

### 3.2 意外发现

**Rerank 精排在本实验中未带来提升，反而略有下降**：

1. **Precision@1 与 MRR 均为 1.0**：两种模式下 top-1 结果均命中 ground truth，说明向量召回已足够准确
2. **norank 在 P@3/P@5 略优**：向量召回的排序本身已较好，rerank 反而将部分相关文档排后
3. **延迟增加 20%**：rerank 调用百炼接口额外耗时约 460ms

### 3.3 原因分析

1. **知识库规模小**：17 篇文档，向量召回已能覆盖相关文档
2. **文档质量高**：标题与内容语义一致，embedding 模型（qwen3.7-text-embedding）已能准确匹配
3. **Query 与文档语义接近**：标准 query 与文档标题高度相关，无需精排修正
4. **Rerank 模型可能过严**：对部分相关文档打分偏低，导致排序下降

### 3.4 适用场景推测

Rerank 精排可能在以下场景更有价值：

- **知识库规模大**（100+ 文档）：向量召回噪声增加，需精排修正
- **Query 与文档语义差距大**：如口语化 query 匹配专业文档
- **文档质量参差不齐**：需精排过滤低质量结果
- **多义词/歧义 query**：需精排区分语义

## 4. 建议

### 4.1 当前项目配置

| 场景 | 建议 |
|---|---|
| 当前知识库（17 篇） | **可关闭 rerank**（`enable_rerank=false`），节省 20% 延迟 |
| 知识库扩展至 100+ 篇 | **重新评估 rerank 价值** |
| 用户 query 多样化 | **保留 rerank 选项**，按需开启 |

### 4.2 代码层面

当前实现已支持 `enable_rerank` 参数切换，无需改动。建议：

- 前端 RAG 检索页面增加"启用精排"开关
- 默认按知识库规模自动选择（<50 篇关闭，>=50 篇开启）

---

## 5. 实验局限性

1. **知识库规模小**：17 篇文档可能不足以体现 rerank 价值
2. **Query 标准化**：标准 query 与文档标题高度相关，实际用户 query 可能更口语化
3. **Ground truth 人工标注**：可能存在主观偏差
4. **未测试失败降级**：rerank 接口异常时的降级路径未验证
